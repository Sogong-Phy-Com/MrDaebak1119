==========================================
🐳 Render Docker 배포 (Java 옵션 없을 때)
==========================================

문제: Java 런타임 옵션이 보이지 않음
해결: Docker 사용!

1️⃣ Render 대시보드
   - "New +" → "Web Service"
   - GitHub 저장소 연결

2️⃣ 설정:
   Runtime: Docker 선택
   Dockerfile Path: server-java/Dockerfile
   Docker Context: server-java

3️⃣ Environment Variables:
   SPRING_PROFILES_ACTIVE = production
   JWT_SECRET = your-strong-secret-key

4️⃣ Health Check Path:
   /api/health

5️⃣ Create Web Service!

==========================================
또는 render.yaml 사용 (자동)
==========================================

1. GitHub에 푸시:
   git add render.yaml
   git commit -m "Docker config"
   git push

2. Render에서 "Infrastructure as Code" 선택
3. render.yaml 자동 인식!
