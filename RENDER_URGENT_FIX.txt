🚨 Render 오류 긴급 해결
==========================================

문제: 여전히 Node.js로 인식됨

✅ 해결: Render 대시보드에서 수동 설정

1️⃣ Render 대시보드 → 서비스 → Settings

2️⃣ 다음 설정 변경:

   Runtime: Node → Docker 변경
   
   Dockerfile Path:
   server-java/Dockerfile
   
   Docker Context:
   server-java
   
   Build Command: 삭제 (비워두기!)
   Start Command: 삭제 (비워두기!)

3️⃣ Environment Variables:
   SPRING_PROFILES_ACTIVE = production
   JWT_SECRET = your-strong-secret-key

4️⃣ Health Check Path:
   /api/health

5️⃣ Save Changes → Manual Deploy

==========================================
⚠️ 중요: Build/Start Command 비워두기!
==========================================
